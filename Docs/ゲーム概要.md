# ゲーム概要
- シングルプレイヤーのオートバトルローグライク
# ゲームループ
## 編成
- 最初にプレイヤーは前衛キャラ、後衛キャラから1体ずつ選び、パーティを結成する
    - キャラクターは全キャラクターの中から自由に選択できる
- 編成は最初の1回のみ行い、以後（ゲームクリアまたはゲームオーバーになるまで）変更はできない
## 戦闘
- 敵が2体出現し、2v2の戦闘になる
- 戦闘は完全に自動で進行し、どちらかが全滅するか、制限時間が来るまで継続する
    - 制限時間になるとプレイヤーの敗北
    - 両者が同時に全滅した場合（相討ち）もプレイヤーの敗北とみなす
- ラウンド開始時、HP・AP・シールドはリセットされる（前のラウンドから持ち越さない）
- 通常攻撃・アクティブスキルの対象は基本的に前衛を優先する
    - 前衛が戦闘不能になった後は、後衛が狙われるようになる
    - ただし、全体攻撃、ランダムな対象を選ぶもの、後衛を狙うものなど、対象選択ルールが異なる効果も一部存在する（効果ごとに個別に定義）
- 敵もプレイヤーキャラと同様に通常攻撃・アクティブスキル・パッシブスキルを持つが、前衛・後衛の区別（ロール）は設けない
- ライフを3つ持ち、戦闘に敗北するたびに1つ減少する。ライフが0になる、またはラスボス戦で敗北するとゲームオーバー
    - 敗北によるペナルティはライフの減少のみで、それ以外（ステータス低下など）は無い
- 戦闘後、勝敗に関わらず報酬のアイテムがもらえる
## 敵の出現
- 通常ラウンド用の敵プールと、4・8ラウンド（中ボス戦）用の敵プールは分けて用意する
- ラスボス（9ラウンド目）は固定の敵とする
- 敵はプールからランダムな順番で出現する（詳細は実装したいデバッグ機能.md「シード値の固定」を参照）
## アイテムの選択・装着
- アイテムがランダムに3つ提示され、1つを選ぶ
    - ラウンドごとにレアリティ（コモン/レア/エピック）の出現重みを指定する
- 選んだアイテムをどちらのキャラにつけるかを選ぶ
    - 片方のキャラが既に4つ装備済みで空きがない場合、選択後に自動的にもう一方のキャラへ装着される
- アイテムによるステータス上昇量はアイテムごとに個別設定する
- アイテムはキャラクターの種類による装着制約を持たない（誰にでも装着可能）
- アイテムによってアクティブスキルが追加されることはない
    - アクティブスキルに付随する効果を持たせたい場合は、「アクティブスキル発動時に○○する」というパッシブスキルとしてアイテムに持たせる（詳細はキャラクター.md「行動(Action)システム」を参照）
戦闘→アイテムの選択・装着を1ラウンドとして、計9ラウンド行う
- ラウンドが進行するごとに敵のステータスが増加する
    - 増加の具体的な計算方法は未定。テストをしながら調整するため、計算方式を柔軟に差し替えられる設計にする（実装したいデバッグ機能.mdにある「戦略クラスの差し替え可能な設計」と同様の考え方を適用する想定）
- 4,8ラウンド目は中ボス、提示されるアイテムは必ずエピック
- 9ラウンド目はラスボス
    - 勝利時、アイテム選択は行わずゲームクリア
    - 敗北時、ゲームオーバー
